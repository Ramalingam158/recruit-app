# AI Usage

AI tools were used as a development and design assistant throughout this assessment. All generated code and architectural recommendations were reviewed, adapted, and verified via integration tests.

### Development & Testing
* **Project & Test Scaffolding:** Accelerated initial setup by generating repetitive boilerplate for project structure and `@SpringBootTest` integration test configurations.
* **Query Validation:** Assisted in reviewing and refining Spring Data JPA `Specification` predicates for multi-field search and filtering endpoints.

### Architecture & Design Decisions
* **Trade-off Analysis:** Used as a sounding board to brainstorm relational modeling and backend design approaches (e.g., evaluating unidirectional `@ManyToOne` vs. `@OneToMany` mappings, query performance, and pagination safety) before selecting the final implementation.
